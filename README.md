# Sustavzaupravljnjeautoservisom
Aplikacija omogućuje učinkovito upravljanje svim aspektima poslovanja autoservisa. Korisnicima je omogućen unos, ažuriranje i pregled podataka o vozilima, klijentima i izvršenim popravcima. Također, aplikacija pruža mogućnost generiranja izvještaja o popravcima, pregleda povijesti vozila te obračuna troškova pruženih usluga.
